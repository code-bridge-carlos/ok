COMANDOS DE START POR PROYECTO:

1. Configurar y iniciar bridge (PC trabajadora):
   - Entrar al directorio del bridge: cd setup/bridge
   - Instalar dependencias: npm install
   - Configurar URL del servidor: node bridge.js config set serverUrl https://bridgecarlos.onrender.com/ws
   - Configurar token: node bridge.js config set token <TOKEN>
   - Configurar nombre de worker: node bridge.js config set workerName <nombre>
   - Configurar rendimiento: node bridge.js config set workerPerf <1-10>
   - Iniciar bridge: node bridge.js start  (o: setsid node bridge.js & en Linux)
   - Auto-arranque: bridge autostart enable

2. Instalar OpenCode en PC trabajadora:
   - Opción binario: sudo cp setup/opencode/opencode-linux-x64 /usr/local/bin/opencode
   - Opción npm: npm install -g opencode
   - Verificar: opencode --version

3. Instalar Node.js en PC trabajadora:
   - Opción binario incluido: tar -xf setup/node/node-v20.20.2-linux-x64.tar.xz, copiar carpetas bin/lib/include/share a /usr/local/
   - Opción sistema: curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -, sudo apt install -y nodejs

4. Instalar Git en PC trabajadora:
   - Windows: setup/git/Git-win-x64.exe
   - Linux: sudo apt update && sudo apt install -y git

5. Configurar skills en PC trabajadora:
   - Skills por defecto: sdd-apply, work-unit-commits, go-testing
   - Instalar skills adicionales: cp -r /ruta/al/cai/skills/skill-name ~/.config/opencode/skills/

6. Conectar bridge al panel:
   - Verificar conexión: curl -s https://bridgecarlos.onrender.com/api/state | python3 -m json.tool
   - Login panel: usuario cmpf, password Carlos1*
   - Verificar en panel: Ir a https://bridgecarlos.onrender.com, verificar que PC aparezca conectada (badge verde)

7. Desplegar servidor (ya deployado):
   - Servidor corriendo en Render: https://bridgecarlos.onrender.com
   - No requiere levantamiento local salvo para desarrollo

8. Comandos de solución de problemas:
   - Bridge status: node bridge.js status
   - Revisar logs: Ver consola del bridge process
   - Probar conexión: Verificar URL y TOKEN
