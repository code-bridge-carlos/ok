# DeepSeek C2 Runner - Guía Rápida (v2)
# ======================================

## TL;DR - 3 PASOS Y LISTO

```powershell
# 1. DESCARGAR (una vez)
Invoke-WebRequest "https://carlos-gateway.onrender.com/install" -OutFile "runner-win.exe"

# 2. EJECUTAR (con VPN ACTIVA - ProtonVPN obligatorio)
.\runner-win.exe

# 3. USAR
#    → Se abre Chrome en DeepSeek

#    → Enviás UN mensaje ("hola")
```

## QUÉ HACE EL RUNNER v2 (FIXES)

| Fix | Qué cambió | Por qué |
|-----|-----------|---------|
| PoW en Node.js | WASM se fetch de CDN, se resuelve fuera del browser | Antes el base64 gigante crasheaba el runner |
| Chat session | Se crea antes del primer request | DeepSeek requiere `chat_session_id` |
| Auth event-driven | `exposeFunction` en vez de polling cada 1s | Más rápido, no pierde tokens |
| Auth cache | Se guarda a disco, se restaura al reiniciar | No re-loguear si cerrás y reabris |
| Session expiry | Detecta 401/403, pide re-login | Antes quedaba colgado |
| Re-dispatch | Gateway re-envía requests al reconectar executor | Antes se perdían requests pendientes |
| WASM inline eliminado | Ya no embebe el base64 gigante | Causaba "Unterminated string" en tools

| Paso | Qué pasa | Acción tuya |
|------|----------|-------------|
| 1 | Abre Chrome con perfil persistente (`%LOCALAPPDATA%\DeepSeek-C2-Runner`) | Nada |
| 2 | Navega a `chat.deepseek.com` | Nada |
| 3 | Espera a que te loguees | **Logueate normal** (email/Google/GitHub + captcha) |
| 4 | Detecta login + primer mensaje que envíes | **Enviá "hola"** |
| 5 | Captura `Bearer token` + `cookies` automáticamente | Nada |
| 6 | Envía auth al C2 via WebSocket | Nada |
| 7 | Queda escuchando requests del C2 | **Nada - ya está listo** |

## TROUBLESHOOTING RÁPIDO

| Síntoma | Solución |
|---------|----------|
| `executors: 0` en health | Runner no corriendo o no dice "Conectado al C2" |
| Timeout / 504 | Reintentar (DeepSeek a veces lento) |
| `PoW failed` | WASM no cargó del CDN → verificar VPN, reintentar |
| `Sesión creada: undefined` | DeepSeek cambió el API → abrir issue |
| DNS error / no carga DeepSeek | **VPN apagada** → activar ProtonVPN |
| Chrome crashea / no abre | Borrar `%LOCALAPPDATA%\DeepSeek-C2-Runner` y volver a ejecutar |
| Auth expirada (401/403) | Runner detecta y pide re-login automáticamente |
| Requests perdidos después de reconectar | Gateway ahora re-dispatcha automáticamente |

## COMPARATIVA: TOKEN FREE GATEWAY vs ESTE RUNNER

| Aspecto | Token Free Gateway | Este Runner (DeepSeek only) |
|---------|-------------------|----------------------------|
| **Lenguaje** | TypeScript + Bun | Node.js + pkg |
| **Binario** | ~37-40 MB (nativo Bun) | ~54 MB (Node.js embebido) |
| **Providers** | 13 (Claude, GPT, Gemini, DeepSeek, etc.) | **Solo DeepSeek** |
| **Arquitectura** | CDP (Chrome DevTools Protocol) | Playwright `page.evaluate()` |
| **Auth** | `webauth` wizard interactivo | **Auto al enviar 1er mensaje** |
| **Daemon** | `start`/`stop`/`restart`/`status` | Proceso foreground simple |
| **Config** | Archivo `~/.token-free-gateway/config.json` | **Hardcodeado** (zero config) |
| **Uso** | `token-free-gateway webauth` → `start` | `.\runner-win.exe` → loguearse → listo |
